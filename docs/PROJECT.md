# BUGs 项目概述

## 项目身份

**BUGs** 是一款设计驱动的跨平台节奏游戏。

### 是什么

- 一款音游，玩法第一
- 设计驱动，不是故事驱动
- 移动端优先，桌面端增强
- 输入无关：键盘、触屏、手柄、MIDI、太鼓、无障碍设备均可
- 开源社区协作，GitHub 哲学

### 不是什么

- ❌ 假操作系统
- ❌ 黑客模拟器
- ❌ 赛博朋克
- ❌ 程序员模拟器
- ❌ 故事/世界观驱动

## 核心原则

1. **设计驱动** — 身份来自交互、UI、动画，不是故事
2. **玩法第一** — 一切服务于游戏体验
3. **输入无关** — 输入和判定完全解耦
4. **开源协作** — GitHub 风格的贡献、审查、迭代
5. **AI 友好** — 任何 AI 模型都能理解本仓库

## 设计语言

借鉴：Microsoft Fluent（间距）、看门狗2（交互节奏）、Steam（组件组织）、终端排版（视觉语言）。

避免：赛博朋克、黑客美学、假代码、过度装饰。

详见 [DESIGN.md](DESIGN.md)。

## 目标平台

- iOS / Android（移动端优先）
- macOS / Windows / Linux（桌面端增强）

## 长期方向

- 社区驱动的谱面创作
- 自定义输入设备支持
- 可扩展的判定系统
- AI 辅助开发工作流
