# 社区指南

## 社区哲学

受 GitHub 启发，不是 GitHub 的 UI。

- **贡献** — 任何人都可以贡献代码、谱面、文档
- **迭代** — 小步快跑，持续改进
- **审查** — 所有变更经过 Review
- **透明** — 决策公开，讨论公开
- **长期** — 项目设计为维护多年
