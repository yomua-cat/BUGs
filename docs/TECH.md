## 模块隔离规则

1. 模块间只能通过 `core/Interfaces/` 通信
2. 模块永远不直接引用另一个模块的实现
3. 每个模块有独立的 `README.md` 记录接口
4. 模块损坏 → 删除文件夹 → 仅丢失该模块功能
5. 接口变更 → 同步更新 `core/Interfaces/` + 所有实现

## 目录结构

```
src/
├── core/Interfaces/    # 接口定义（唯一共享层）
├── audio/              # 音频模块（miniaudio 封装）
├── input/              # 输入模块
├── gameplay/           # 玩法模块（判定、计分）
├── chart/              # 谱面模块（自定义格式）
├── ui/                 # UI 模块
└── platform/           # 平台适配
```
