# BUGs

跨平台音游。设计驱动。输入无关。开源。

## 这是什么

BUGs 是一款设计驱动的跨平台节奏游戏。不是假操作系统，不是黑客模拟器，不是赛博朋克。

**核心身份**：现代 UI 设计 × 输入无关玩法 × 开源社区协作。

## 技术栈

| 层 | 选型 |
|----|------|
| 游戏引擎 | Unity 6 |
| 编程语言 | C# |
| 音频引擎 | miniaudio |
| 谱面格式 | 自定义（BUGs Chart Format） |
| 许可证 | MIT |

## 快速开始

> 需要 Unity 6+ 和 .NET SDK。

```bash
git clone https://github.com/yomua-cat/BUGs.git
# 用 Unity Hub 打开项目
# 点击 Play
```
