# BUGs

> 一款跨平台节奏游戏。
> 目前还在概念阶段。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

BUGs 是一款节奏游戏——跟着音乐节拍操作，获得分数。

- **跨平台**：手机和电脑都能玩
- **输入自由**：键盘、触屏、手柄都能用
- **开源**：全部代码公开

> ⚠️ 项目还在美术概念设计与验证阶段，暂时啥都玩不了。
