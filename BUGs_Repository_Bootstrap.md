# BUGs Repository Bootstrap

## Project Overview

**Name:** BUGs (codename)

BUGs is a cross-platform rhythm game focused on modern UI design,
input-agnostic gameplay, and long-term community collaboration.

### Core Principles

-   Design-driven, not story-driven.
-   Mobile-first gameplay.
-   Desktop provides richer visual presentation.
-   Input-agnostic judgement: any valid input may trigger any judgement.
-   Community inspired by GitHub collaboration, not GitHub's UI.
-   Terminal is a visual language only.

## Coding Philosophy

-   Modular architecture.
-   Documentation before implementation.
-   Small tasks.
-   AI-friendly project structure.
-   Clear naming.
-   Avoid giant files.
-   Every feature should have documentation.

## Development Workflow

1.  Write/update documentation.
2.  Record design decisions.
3.  Break work into small tasks.
4.  Implement.
5.  Review.
6.  Refactor.
7.  Commit.

## Design Constraints

Avoid: - Cyberpunk - Hacker aesthetics - Fake code - Excessive visual
effects - Hexagons - RGB lighting - Scanlines - Glassmorphism

Prefer: - Modern desktop software - Microsoft Fluent spacing - Watch
Dogs 2 interaction rhythm - Steam component organization - Rectangular
layout - Minimal visual language

## Repository Goal

The repository should become a long-term maintainable project that both
humans and AI agents can understand immediately.
